## A Free Music Pack for Minstrel

Ten playlists of Kevin MacLeod's music, each with album art and crossfade already set up for [Minstrel](https://wiki.3deathsaves.com/minstrel/). Without Minstrel, they play as ordinary Foundry playlists.

## Installation

Find **Minstrel: Music I** in Foundry's Module Browser, or paste this manifest URL:

```
https://github.com/Sayshal/minstrel-packs-music-01/releases/latest/download/module.json
```

The playlists appear in the Compendium Packs sidebar under **Minstrel Audio Packs**. In Minstrel, click an album marked **Content pack**, then **Import to world**.
